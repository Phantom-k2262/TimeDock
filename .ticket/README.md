# チケット運用

このフォルダをプロジェクトのタスク管理台帳として使用します。チケットはMarkdownで管理し、作業の進行に応じて状態フォルダ間を移動します。

## 種類

- `feature`: 新機能・機能改善
- `bugs`: 不具合・回帰・修正
- `issue`: 技術課題、調査、運用課題、意思決定待ち

## 状態

`01_new` → `02_active` → `03_wait` → `04_close`

- `01_new`: 未着手
- `02_active`: 作業中
- `03_wait`: 外部情報・ユーザー判断・依存作業待ち
- `04_close`: 完了・検証済み
- `05_removed`: 取り下げ、重複、誤登録。削除せず理由を残して移動

状態を変更するときは、チケットの `status`、`updated`、`activity` を更新してからファイルを移動します。ファイル名は `T####-短い英語名.md` とします。

## チケット番号

種類をまたいで重複しない4桁番号を使用します。次の番号は既存最大番号の次を採番してください。

## 完了条件

実装・テスト・ドキュメント更新・レビュー結果をチケットに記録してから `04_close` へ移動します。未実行のテストを完了扱いにしません。
