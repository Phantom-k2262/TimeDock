# BUG-ABCS-001 入力用シートの日別キャッシュ列ずれ

- 種別: bug
- 重大度: High
- 状態: 01_new
- 対象: `勤務表（入力用）` D:AH、特に F/J/R/X/AE と G/L/S/AA/AG

## 事象

勤務データのない日付列に15行目・24行目のキャッシュが残り、反対に勤務データのある列の日別計算が空欄になる。共有数式の子セルと、入力値の列対応を含めて調査する。

## 対応方針

日付列を `work_date` の日番号から一意に決定し、共有数式の親子セルを含む全対象セルのキャッシュを同じ列へ更新する。未入力日はテンプレートの古いキャッシュを残さない。数式本文、書式、VBAは変更しない。

## 受入条件

- 指定列の入力値と15/18:24行の計算列が同じ日付列に対応する。
- 未入力日に730等のテンプレート由来キャッシュが残らない。
- 入力データのある G/L/S/AA/AG などが計上される。
- 共有数式の親式・数式本文・VBA・スタイルを保持する。
