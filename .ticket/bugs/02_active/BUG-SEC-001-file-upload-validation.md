# BUG-SEC-001 ファイルアップロードの安全検査不足

- 種別: bug
- 重大度: High
- 状態: 02_active
- 参照: `reports/LEGAL_SECURITY_AUDIT.md` SEC-001

## 事象

アップロード時の拡張子、Content-Type、マジックバイト、Officeマクロ、悪意あるファイル、圧縮爆弾の検査が十分に確認できない。

## 影響

悪意あるファイルや意図しない形式のファイルが保存・共有され、利用者の端末やブラウザで実行・解釈される可能性がある。

## 確認方法

ステージング環境で偽装Content-Type、HTML/SVG、マクロ付きOffice、過大ファイル、同名ファイルをアップロードし、保存・ダウンロード時の検査とContent-Dispositionを確認する。

## 対応方針

許可形式のallowlist、内容検査、展開後サイズ上限、マルウェアスキャン、R2キーと表示名の分離、ダウンロード時のattachment固定、操作監査を実装する。

## activity

- 2026-11-17: allowlist、拡張子とマジックバイト検査、ファイル名サニタイズ、R2キー分離、nosniff/no-storeを実装。マルウェアスキャンとzip展開検査は継続課題。
