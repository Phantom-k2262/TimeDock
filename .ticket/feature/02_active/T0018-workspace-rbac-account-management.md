# T0018 ワークスペース・フォルダ権限・アカウント管理

## 目的

勤務表以外も扱える任意名のワークスペースを提出単位として作成し、配下にメンバーフォルダを自動生成する。管理者とメンバーの操作範囲を明示し、フォルダ単位の読み取り専用・参照権限をサーバーで管理する。

## 受け入れ条件

- [ ] 画面上に管理者/承認者/メンバーの権限を表示する
- [x] メンバーが自分のパスワードを変更できる
- [x] パスワードは記号・英数字8〜20文字、強度表示、確認入力を行う
- [x] メンバーが任意名のワークスペースを作成できる
- [x] ワークスペース作成時にメンバーフォルダを生成する
- [x] 管理者がアカウント作成・無効化・表示名変更・パスワード変更を行えるAPI/UIを追加する
- [x] 管理者がワークスペースを削除できる
- [x] フォルダごとに読み取り専用とホワイト/ブラックリストモードを保持できる
- [x] 参照権限を剥奪されたユーザーをワークスペース一覧から除外する
- [ ] 全ファイル操作、監査ログ、細粒度ACLのE2Eを追加する
