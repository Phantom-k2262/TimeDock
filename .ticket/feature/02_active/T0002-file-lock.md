# T0002 R2版管理とチェックアウトロック

## 目的

`.xlsx`の不変版保存、排他リース、ダウンロード、チェックイン、CAS競合検出を実装する。

## 受け入れ条件

- [ ] R2バケットを非公開で扱う
- [ ] 同一勤務表の有効ロックを最大1件にする
- [ ] 期限切れ・古いtoken・古いversionを409で拒否する
- [ ] Idempotency-Keyで再送時の二重版作成を防ぐ
- [ ] 拡張子・サイズ・ZIP構造を検証する
- [ ] 同時チェックアウト20件の受け入れテストを追加する
