# T0017 管理者の月次ZIPアーカイブ

## 目的

管理者が対象月を指定し、全社員の個人フォルダを元の階層のままZIPで取得できるようにする。

## 受け入れ条件

- [ ] adminセッションだけが月次アーカイブAPIを実行できる
- [ ] 対象月の勤務表・経費・領収証を個人名フォルダへ分類する
- [ ] ZIP内に`個人名/勤務表ファイル`と`個人名/経費・領収証`を保持する
- [ ] 元のR2オブジェクトは変更・削除しない
- [ ] 対象ファイルがない月は安全な404を返す
- [ ] アーカイブ作成を監査ログへ記録する

## activity

- 2026-11-17: 保存形式、ZIP生成ユーティリティ、admin API、管理画面の仮実装と14件のAPIテストを追加。監査ログ・大容量制御・実ドキュメント登録は未実装。
