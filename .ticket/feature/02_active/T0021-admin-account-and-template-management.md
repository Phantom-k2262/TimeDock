# T0021 管理画面のアカウント・テナント・ワークスペース管理

## 受け入れ条件

- [x] アカウントの追加・論理削除・停止・停止解除を行える
- [x] アカウント一覧を検索、状態、テナント、権限で絞り込み、並び替えできる
- [x] 停止中アカウントはログインできるがテナント・ワークスペースを表示しない
- [x] テナントを追加・削除できる
- [x] ワークスペースへ管理者がファイルを追加できる
- [x] テンプレートをワークスペースへ紐づけ、ワークスペース上部から読み取り専用で参照できる
- [x] ワークスペース作成フォームが画面幅からはみ出さない
- [ ] 本番D1へ0008マイグレーションを適用して動作確認する
