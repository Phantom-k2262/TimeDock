# T0019 TOTP二段階認証

## 目的

システム管理者を除くユーザーのログインを、認証アプリの6桁TOTPコードで保護する。外部メールサービスを使わず、無料で運用できる構成にする。

## 受け入れ条件

- [x] 初回ログイン時に認証アプリ登録画面を表示する
- [x] 登録完了までダッシュボードへの遷移を禁止する
- [x] 登録済みユーザーもログインセッションごとにTOTP検証を行う
- [x] システム管理者は二段階認証の対象外にする
- [x] システム管理者・システム作業者がユーザー単位で必須設定を変更できる
- [x] 秘密鍵の手入力とotpauth URIの登録に対応する
- [ ] QRコード表示、バックアップコード、再登録フローを追加する
- [ ] 本番D1へマイグレーションを適用して動作確認する
