# T0016 個人フォルダアップロードと読み取り専用テンプレート

## 目的

管理者がテンプレートを配布用フォルダへ配置し、社員がテンプレートを取得して個人フォルダへ勤務表をアップロードできるようにする。

## 受け入れ条件

- [ ] `template_library`フォルダは社員が閲覧・ダウンロードのみ可能
- [ ] `personal`フォルダは所有社員だけがアップロード・更新可能
- [ ] 管理者はテンプレートの追加、更新、削除（参照中は論理削除）が可能
- [ ] UIとAPIの両方でフォルダ権限を検証する
- [ ] 他人の個人フォルダ・ファイルはID推測だけで閲覧できない
- [ ] `.xlsx`、10MiB以下、SHA-256付きの版管理を維持する
