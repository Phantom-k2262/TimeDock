# T0003 勤務表の提出・承認・差戻し

## 目的

勤務表の状態遷移、承認者割当、監査履歴を実装する。

## 受け入れ条件

- [ ] draft/rejectedから提出できる
- [ ] submitted中の編集を拒否する
- [ ] 割当済み承認者または管理者だけが承認・差戻しできる
- [ ] 差戻し理由を必須にする
- [ ] 版番号・SHA-256・操作主体を監査履歴へ記録する
