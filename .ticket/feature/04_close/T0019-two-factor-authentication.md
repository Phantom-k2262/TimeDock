# T0019 TOTP二段階認証

## 目的

システム管理者を除くユーザーのログインを、認証アプリの6桁TOTPコードで保護する。外部メールサービスを使わず、無料で運用できる構成にする。

## 受け入れ条件

- [x] 初回ログイン時に認証アプリ登録画面を表示する
- [x] 登録完了までダッシュボードへの遷移を禁止する
- [x] 登録済みユーザーもログインセッションごとにTOTP検証を行う
- [x] システム管理者は二段階認証の対象外にする
- [x] システム管理者・システム作業者がユーザー単位で必須設定を変更できる
- [x] 秘密鍵の手入力とotpauth URIの登録に対応する
- [x] QRコード表示（秘密鍵の手入力フォールバックを含む）
- [x] 登録済みユーザーの再ログインでは秘密鍵・QRを再表示せず、6桁コードだけを要求する
- [x] システム管理者・システム作業者による明示的な二段階認証リセット後だけ再登録可能にする
- [x] バックアップコードを追加する
- [x] 本番D1へマイグレーションを適用する

## activity

- 2026-11-17: QRコード生成表示と長い登録URIの折り返しを追加。Web資産をビルドしてからWorkerへデプロイする運用に修正。
- 2026-11-17: 登録済みの秘密鍵・QRの再表示を禁止し、管理者リセットAPIと全セッション無効化を追加。
