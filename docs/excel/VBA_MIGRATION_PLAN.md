# VBA移植計画

1. 管理者が承認したテンプレートのコピーからVBAソースを抽出し、標準モジュール、シート、ThisWorkbook、UDF、イベント、ボタン呼出しを一覧化する。
2. UDFを入力・出力の表に変換し、Excelセル番地ではなく`DailyAttendanceInput`等のドメイン型で再現する。
3. A分類の勤務時間・普通休憩・深夜休憩・残業・休日・遅刻早退を純粋関数に移植し、VBA実行結果とのfixture比較を追加する。
4. B分類は`WorkbookEditor`のマッピングへ移し、初期化は「テンプレート識別・氏名／月設定・入力域クリア・Web値反映」の順序を固定する。
5. C/D分類はWeb GUIまたは出力時の限定セル更新へ分割する。Excel固有のイベントに依存する処理は自動移植せず未対応として返す。
6. E分類はExcel本体が必要な機能として明示し、Web出力の成功条件に含めない。

VBAソースが得られるまで、現実装はVBAを保持し、Workers側はUDFを「未評価」と記録する。`#NAME?`を数値に置き換えて隠す実装は行わない。
