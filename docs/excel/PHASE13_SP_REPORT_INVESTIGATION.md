5. このcheckoutの `attendance.ts` では、ABCS専用入力チェックが出力形式別に分離された実装は確認できない。ABCSの既存チェックを維持したまま、新帳票に適用しないことを回帰テストで確認する必要がある。

## 12. 最新の実障害回帰対応

- `A12:A42` と `B12:B42` の数式本文は保持し、対象月から日付・曜日のキャッシュを再生成する。対象月外の行は `t="str"` の空キャッシュにするため、テンプレート月の残存値を出力しない。
- `C12:E42` と `G12:H42` は出力前にクリアし、勤務データが存在する日付行だけへ反映する。`G:H` は結合された備考欄であり、作業時間の計算値を書き込まない。
- 休憩時間は分数をテンプレート仕様のHHMM値へ変換する。60分は `100`（`01:00`）、75分は `115` とする。`00:60` は出力しない。
- `F/J/K/L` の数式本文と共有数式の親子関係を保持したまま、数値キャッシュだけを更新する。
- SP帳票では古い `xl/calcChain.xml` を削除し、`workbook.xml` に自動・全再計算を指定する。これにより、変更済みキャッシュと古い計算チェーンの不整合を残さない。
- 作業実績表の合計行 `K43` は日別 `K12:K42` の合計キャッシュを更新し、共有数式子セル `F43` も同じ合計を `HHMM` 値へ変換して更新する。テンプレートに残っていた `30:45` の古いキャッシュを再利用しない。
- ABCS提出用シートの参照数式は、結果が数値なら既存の `t="str"` を除去し、空文字列なら `t="str"` を付与する。数値キャッシュを文字列型で保存してExcel修復を誘発する状態を回帰テストで検出する。
- `refreshSubmissionReferenceCaches` が自己終了型の `<c .../>` を通常セルとして扱うと、後続セルを巻き込んで `sheet4.xml` を壊すため、自己終了型とペア型を分けて処理する。共有数式の削除やセル欠落を招かないことを実テンプレートのXMLパーサー回帰テストで確認する。
- `xl/calcChain.xml` を削除する場合は、パーツ本体だけでなくリレーションと `[Content_Types].xml` の参照も同時に除去する。これらを残すとExcel起動時の構造不整合になるためである。

- 実テンプレートを使う回帰テストは29件成功し、API/Webの型チェック、Webテスト、ビルド、`git diff --check` も成功した。Excel実機での再オープン・印刷プレビューはこの環境では未検証である。
