# VBA解析結果

## 取得できた事実

- 対象XLSMには `xl/vbaProject.bin` が存在する。
- 現環境ではVBAソースを安全に抽出・実行するExcel COM／`olevba`環境を確認できなかったため、標準モジュール、シートモジュール、ThisWorkbookのコード本文は未取得。
- ワークシート数式から、`勤務時間` 4件、`残業時間` 12件、`COUNTIF2` 1件、`代休取得時間` 1件、`遅刻早退時間` 1件のカスタム関数参照を確認した。
- スクリーンショットの`#NAME?`とマクロブロック表示は、VBA/UDFが評価できない場合の症状と整合するが、コード本文未取得のため因果は未確定。
