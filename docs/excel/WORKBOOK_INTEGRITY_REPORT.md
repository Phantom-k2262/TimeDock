# ブック整合性レポート

## 検証結果

- 合成fixture: VBAパーツ、名前定義、共有数式、セルスタイル、入力／提出用シート参照を保持して通過。
- 実テンプレート: 出力後もVBAバイナリSHA-256が一致し、ZIPパーツ数は`calcChain.xml`の意図的除去を除き一致。
- 非対象パーツ: `validateWorkbookIntegrity`で変更・欠落・追加を検出し、許可外なら出力をエラーにする。
- 許可変更: `xl/workbook.xml`、選択された対象ワークシート、`xl/calcChain.xml`。VBAバイナリは許可していない。

## 既知の限界

`workbook.xml`と対象ワークシートは許可パーツ単位で扱うため、パーツ内の差分をさらにセル単位で監査するにはテンプレートごとのマッピング定義が必要です。名前付き範囲は検査できますが、現行のABCSマッピングは既存仕様との互換性のため固定番地フォールバックを残しています。構造不一致時に自動補正せずエラー化する仕組みは、今後テンプレート登録時の検証へ拡張します。
